# Fase1.Analisis
Realizamos un análisis para crear nuestro videojuego donde vimos sobre que trataría, la cual es un adolescente fanático de las películas de zombies que, tras un fallo extraño en su televisión, es absorbido dentro de ella. Al entrar en ese mundo, descubre que ahora tiene poderes especiales y debe enfrentarse a un universo lleno de zombies y peligros para poder salir de ese mundo y salvar a las personas de que también están atrapados. y también para que tipo de publico diseñado para niños de 11 a 15 años, ofreciendo una propuesta atractiva sobre zombies pero con un nivel de violencia moderado.

# Fase2.Diseño
Mi diagrama detalla la lógica del videojuego "JuegoZombieTV", donde inicias con 100 de vida, 2 pociones y el objetivo de recolectar 3 piezas para reparar un portal y escapar de la televisión. Durante cada turno, puedes elegir "Explorar" para enfrentar a un zombie (donde acertar la habilidad te otorga una pieza y fallar te resta 20 de vida) o "Tomar poción" para recuperar 40 de vida a cambio de una unidad; el juego finaliza en victoria si logras reunir las 3 piezas, o en derrota si tu vida llega a 0 antes de conseguirlo.

# Fase3.Desarrollo
Mi código en Python es un videojuego de texto donde un personaje absorbido por la televisión debe recolectar 3 piezas para activar un portal y escapar antes de morir. Utiliza programación orientada a objetos con las clases ElementoJuego, Jugador y Juego para gestionar un menú interactivo por turnos, donde el jugador decide entre buscar piezas, pelear con zombies perdiendo vida, comer hamburguesas para sanar o intentar activar el portal, resultando en victoria al escapar o Game Over si la vida llega a cero.
